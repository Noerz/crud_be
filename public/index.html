CRUD API Service

Sederhana, cepat, dan modular. Endpoint versi ada di /api/v1. Gunakan layanan ini untuk autentikasi pengguna dan pengelolaan catatan (notes).

💓 Health Check 🔗 Repository

🔐 Autentikasi

Registrasi, login, dan validasi token untuk mengakses resource privat.

  • POST/api/v1/auth/register
  • POST/api/v1/auth/login
  • GET/api/v1/auth/me

📝 Notes

Buat, baca, ubah, dan hapus catatan milik pengguna yang terautentikasi.

  • GET/api/v1/notes
  • POST/api/v1/notes
  • PUT/api/v1/notes/:id
  • DELETE/api/v1/notes/:id

💚 Status Layanan

Periksa kesehatan aplikasi dan waktu saat ini untuk kebutuhan monitoring.
